# Sales-Data-Analysis
I designed an interactive Power BI dashboard to visualize sales performance indicators.
Key insights include:

- Top-selling products
- Sales comparison across categories
- Orders distribution by city and customer age
- Monthly order trends

This dashboard provides a clear understanding of market trends and customer behavior, supporting data-driven decision-making.
